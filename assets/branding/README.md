# NIL creator artwork

These four original files were supplied by **babakyaghoobii** for NIL Config Catcher and are preserved byte for byte:

- `nil-logo-transparent.png` and `nil-logo-transparent.svg`
- `nil-logo-charcoal.png` and `nil-logo-charcoal.svg`

Both PNGs are 1254 × 1254. The SVGs wrap embedded PNG artwork; they are not editable vector lettering. They contain no external references or scripts.

Run `npm run icons` after `npm ci --ignore-scripts` to generate the web, iPhone, maskable, macOS and Linux icon files with the pinned Tauri CLI. The charcoal artwork provides contrast for application icons; the transparent artwork is also available in the web app. Only image sizing and maskable padding are applied. The original files are kept outside the public directory so offline installation does not download duplicate full-size originals.
